# Rivojlantirish yo‘li

## Tayyor

- 0-moduldagi 6 dars va Node.js/npm tasdiqlash nazorati.
- 48 dars: nazariya, qatorlar izohi, 3 daraja amaliyot, xato laboratoriyasi, mini-vazifa.
- Har darsda 5 savol, izohli javoblar va yakuniy nazorat.
- Matnda berilgan 45 masala: formula, mustaqil kod, yashirin yechim va tekshiruvlar.
- Worker izolyatsiyasi, vaqt chegarasi, qo‘lda to‘xtatish va o‘quv DOM adapteri.
- Rangli kod, mobil ko‘rinish, rejimlar, qaydlar, qoralamalar va eksport/import.
- Mahalliy video/subtitr/transkript va davom ettirish arxitekturasi.
- Ishlaydigan mustaqil mini-test loyihasi; unit/brauzer sinovlari va build.

## Kontentni kengaytirish

- Har mavzu uchun qo‘shimcha mustaqil mashqlar.
- O‘rnatish bosqichlarining haqiqiy skrinshotlari.
- Video darslar va kontent tahriri.

## Keyingi mahsulot bosqichi

- Backend/baza, login va o‘quvchi/mentor/admin rollari.
- Qurilmalararo progress, API storage adapteri va konfliktlarni hal qilish.
- Server judge uchun operatsion tizim darajasidagi resurs/tarmoq izolyatsiyasi.
- Alohida origin’da to‘liq brauzer DOM muhiti.
- CMS, video yuklash/CDN, YouTube Player API orqali vaqtni saqlash.
- CI, monitoring, avtomatik deploy va katta kontent uchun lazy loading.
